# Regenerating the API client — what to delete afterwards

`src/client/` is generated by `@hey-api/openapi-ts` (`pnpm generate-api`), and
has not been regenerated since several endpoints and columns were added. Every
gap has been bridged by hand, deliberately and consistently, because
regenerating rewrites all ~1500 lines of the client and that is a change worth
making on its own rather than folded into a feature.

This file is the checklist for the session that does it. Everything listed
here exists *only* because the client is stale; each one should disappear.

## Delete after regenerating

- `src/components/auth/useMicrosoftSignInMutation.ts` hand-writes the POST to
  `/users/microsoft` through the generated `client`, because `sdk.gen.ts`
  predates that endpoint. After regenerating, replace the whole `client.post`
  call with `signInWithMicrosoftUsersMicrosoftPost` and drop the
  `{ 200: ... } / { 422: ... }` response-shape generics, which exist only to
  imitate what the generator would have written. Its test mocks
  `@/client/client.gen.ts`; that mock should become a mock of `@/client`, like
  the Google one beside it.

## How to regenerate

The config reads the schema from a running backend:

```
# openapi-ts.config.ts -> input: 'http://localhost:8000/openapi.json'
pnpm generate-api
```

The backend's committed `openapi.json` is guaranteed current — a test fails if
it drifts — so pointing the generator at that file instead is equivalent and
needs no server:

```
npx @hey-api/openapi-ts -i ../math-be/openapi.json -o src/client
```

After regenerating, run `npx tsc --noEmit -p tsconfig.app.json`. Most of the
work below will surface as "this cast is unnecessary" or as a type that no
longer matches; the rest has to be found from this list.

## A. Narrowing casts for fields the client does not know about

Each reads a real column through `as { … }`. After regeneration the field is on
the type and the cast is noise.

`GoogleSignInButton.tsx` and `DiagnosticAdminReportPage.tsx`. Those narrow
genuinely-unknown values (an error body, router state) and are unrelated to the
client's age.

## B. Hand-written request shapes

These call `client.get`/`client.post` directly with a hand-written response
type, because the generated function does not exist yet. Replace each with the
generated function and delete the local type.

| File | Endpoint | Local types to delete |
| --- | --- | --- |
| `src/hooks/diagnostic/useMyAttemptsQuery.ts` | `GET /diagnostic/attempts` | uses `StudentAttempt` from `lib/myResults.ts` |
| `src/hooks/diagnostic/useAttemptReviewQuery.ts` | `GET /diagnostic/attempts/{id}/review` | `ReviewOption`, `ReviewQuestion`, `AttemptReview` |
| `src/lib/analytics.ts` | `POST /analytics/events` | `AnalyticsEventName` — replace with the generated union |
| `src/components/diagnostic/exam/PostSubmissionSurvey.tsx` | `POST /users/diagnostic-survey` | inline `save()` body |
| `src/components/auth/emailCodeApi.ts` | `POST /users/email-code`, `.../verify` | predates this work; check whether the generator now covers it |

`src/lib/myResults.ts` defines `StudentAttempt` by hand for the same reason —
after regeneration it should alias the generated row type rather than restate
it.

## C. Widened write payloads

| File | What | Why |
| --- | --- | --- |
| `src/components/diagnostic/questionForm/types.ts` | `solutionFields()` returns `Record<string, unknown>` | Spread avoids the excess-property check on `CreateDiagnosticQuestionBody` / `UpdateDiagnosticQuestionBody`. Once those carry the solution fields, inline the two properties and delete the helper. |
| `src/lib/signupAttribution.ts` | returns `Record<string, unknown>` | Same reason, for `acquisition` / `agentCode` on the three signup bodies. |
| `src/components/auth/emailCodeApi.ts` | `body: { … } & Record<string, unknown>` | Widened so attribution can ride along. |
| `src/components/auth/useSignupMutation.ts` | `body as UserSignup` | Cast exists only because the spread widens the object. |

## D. Type mirrors to collapse

`src/lib/analytics.ts` restates the backend's `EventName` Literal from
`app/models/analytics.py`. These are meant to be the same list, and today
nothing enforces it — a name added on one side and not the other fails at
runtime with a 422 rather than at compile time. After regeneration, import the
generated union and delete the local one; that is the point at which the two
can no longer drift.
